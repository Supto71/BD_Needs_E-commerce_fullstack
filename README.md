# BD Needs

A full-stack e-commerce web application where customers can browse products, add them to a cart and place orders online.

🌐 **Live site:** [bdneeds.com.bd](https://bdneeds.com.bd/)

## Features
- Browse a wide range of products across categories
- Add products to the shopping cart
- Place orders online

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/Supto71/BD_Needs_E-commerce_fullstack.git
   cd BD_Needs_E-commerce_fullstack
   ```
2. Install dependencies
   ```bash
   npm install
   ```
3. Copy `.env.example` to `.env` and fill in your values
4. Run the development server
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000)
